    Signature-Based Intrusion Detection

    The signature-based IDS detects known attack patterns using predefined rules derived from historical intrusion signatures.

    Attack Type Detected Count

    Anomaly-Based Intrusion Detection (ML)

    The anomaly-based IDS employs a Random Forest classifier to identify deviations from learned normal traffic behavior, enabling detection of unknown or zero-day attacks.

    The bar graph illustrates classification results produced by the trained machine learning model.

    Hybrid IDS Final Decision

    The hybrid decision engine combines outputs from both detection approaches. If an intrusion is detected by either mechanism, the traffic is classified as malicious.
